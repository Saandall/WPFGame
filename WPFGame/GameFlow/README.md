# GameFlow

Директория содержит игровую логику, которая находится уровнем выше отдельных комнат и сущностей.

На первом этапе здесь реализован общий механизм взаимодействия удержанием клавиши.

## `InteractionZone`

`InteractionZone` не знает, что такое станция, поезд или дверь.

Он хранит:

- `Bounds` — мировую область взаимодействия;
- `Prompt` — текст подсказки;
- `HoldDuration` — сколько секунд нужно удерживать кнопку;
- `HoldProgress` — текущий накопленный прогресс;
- `IsPlayerInside` — находится ли игрок внутри области.

### `Update`

Метод получает:

```text
playerHitBox
isInteracting
deltaSeconds
```

Если игрок находится внутри зоны и удерживает кнопку, прогресс растёт.

Если игрок:

- отпускает кнопку;
- выходит из зоны,

прогресс сбрасывается.

После полного удержания `Update` возвращает `true` только один раз за текущее нахождение внутри зоны.

Это защищает от многократного срабатывания при зажатой `E`.

### `GetProgressRatio`

Возвращает значение от `0` до `1` для HUD.

### `Reset`

Полностью сбрасывает состояние зоны.

---

## `InteractionPrompt`

HUD-представление взаимодействия.

Самостоятельно добавляет панель в `Viewport`, поэтому подсказка не двигается камерой.

Содержит:

- текст;
- progress bar.

### `Show`

Показывает текст и текущий прогресс `InteractionZone`.

### `Hide`

Скрывает панель и сбрасывает визуальный progress bar.

### `Remove`

Удаляет панель из `Viewport`.

Метод понадобится позднее при смене целой игровой сцены.

# Текущий тест

В `MainWindow` возле spawn первой станции временно создаётся прямоугольная зона.

Она расположена относительно `CurrentOriginX/Y` стартовой комнаты, а не в абсолютной точке всего мира.

При входе появляется:

```text
Удерживайте E, чтобы покинуть уровень
```

Требуется удерживать `E` примерно `0.8` секунды.

После полного удержания пока выполняется только:

```text
[INTERACTION] Station exit completed.
```

в Debug Output.

На этом этапе уровень не удаляется и поезд ещё не создаётся.
